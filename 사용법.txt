십자가성경 - 안드로이드 / 지인 공유용 사용법
=================================
※ 이 폴더는 "휴대폰에서 쓰거나, GitHub Pages로 배포해서 지인들과 공유하기 위한 버전"입니다.
   윈도우 컴퓨터에서 쓰실 때는 별도로 드린 "십자가성경_윈도우용" 파일을 이용해 주세요.

■ 가장 권장하는 방법 - GitHub Pages로 배포 후 링크 공유
  1. 컴퓨터에서 github.com 에 무료 계정을 만듭니다. (이미 있으면 생략)
  2. 로그인 후 오른쪽 위 '+' → 'New repository'로 새 저장소를 만듭니다.
     이름은 영어로 자유롭게(예: sipjaga-bible), Public(공개)으로 두고 생성합니다.
  3. 저장소 화면에서 'Add file' → 'Upload files'를 누른 뒤, 이 zip을 풀어서 나온
     "십자가성경_안드로이드공유용" 폴더 자체를 화면 안으로 통째로 끌어다 놓습니다.
     (css, js, data, icons 폴더가 함께 올라가야 합니다)
  4. 'Commit changes'를 눌러 업로드를 확정합니다. (파일이 많아 몇 분 걸릴 수 있습니다)
  5. 저장소 'Settings' → 'Pages'로 들어가 Source를 'Deploy from a branch',
     Branch는 'main' / '/ (root)'로 설정하고 저장합니다.
  6. 1~2분 뒤 같은 화면에서 https://아이디.github.io/저장소이름/ 주소가 나타납니다.
  7. 휴대폰 크롬에서 이 주소로 접속한 뒤, 메뉴(⋮)의 "앱 설치" 또는 "홈 화면에 추가"를
     누르면 설치가 끝나고, 이후 홈 화면 아이콘만 누르면 전체화면 앱처럼 바로 열립니다.
  8. 이 주소를 카카오톡이나 메일로 가까운 지인들에게 보내드리면, 각자 7번 과정만
     반복하면 됩니다.

  ※ 검색엔진에 노출되지 않도록 robots.txt와 noindex 설정을 이미 넣어두었습니다.
     그래도 완전한 비공개는 아니므로, 아주 가까운 소수의 지인들에게만 링크를 알려주세요.
     포함된 번역본들은 각 기관이 저작권을 가진 성경이라는 점도 꼭 유념해 주시기 바랍니다.

■ 간단히 휴대폰에서만 직접 열어보는 방법 (배포 전 확인용, 불안정할 수 있음)
  1. 폴더를 통째로 zip으로 압축해 휴대폰으로 옮깁니다.
  2. 파일관리자 앱에서 압축을 풀고, index.html을 눌러 "Chrome으로 열기"를 선택합니다.
  3. 다만 안드로이드 크롬은 이렇게 로컬 파일을 직접 여는 방식(file://)을 불안정하게
     처리해서, "사이트에 연결할 수 없음" 오류가 나중에 다시 나타날 수 있습니다.
     여러 번 안정적으로 쓰시려면 위의 GitHub Pages 방법을 권해 드립니다.

■ 주요 기능
  - 왼쪽 상단 ☰ 버튼을 누르면 책/장 목록이 옆에서 펼쳐집니다.
  - 상단 드롭다운에서 번역본(버전)을 선택할 수 있습니다.
  - 상단 검색창에 단어를 입력하고 검색하면 현재 선택된 번역본 전체에서 찾아줍니다.
  - 절 번호를 클릭하거나 § 아이콘을 누르면 관주(관련 구절) 2~3개가 나타납니다.
  - ✐ 아이콘을 누르면 해당 절에 한 줄 메모를 남길 수 있습니다.
  - ★ 아이콘으로 즐겨찾기에 추가/삭제할 수 있고, 상단 ★ 버튼으로 즐겨찾기 목록을 볼 수 있습니다.
  - ✎ 아이콘을 누르면 하이라이트 색상이 순서대로 바뀝니다 (없음 → 노랑 → 초록 → 분홍 → 없음).
  - 상단 ⇄ 버튼으로 최대 4개 번역본을 동시에 비교해서 볼 수 있습니다.
  - 상단 📖 버튼으로 매일 성경 읽기(1년 통독 계획)를 확인하고 오늘 읽기를 체크할 수 있습니다.
  - 상단 🔊 버튼을 누르면 현재 화면의 본문을 음성으로 읽어줍니다.
  - 상단 🖨 버튼으로 인쇄(또는 PDF로 저장)할 수 있습니다.
  - A- / A+ 버튼으로 글자 크기를, ☾ 버튼으로 다크 모드를 전환할 수 있습니다.

■ 데이터 저장
  - 메모, 즐겨찾기, 하이라이트, 읽기 진도는 이 휴대폰의 이 브라우저(앱)에 자동으로 저장됩니다.
  - 컴퓨터에서 쓰던 내용과는 자동으로 연동되지 않습니다. (각 기기에 따로 저장됩니다)

    유지된 채 지인들 화면에도 최신 내용이 자동으로 반영됩니다.
